# UI Design System

## Palette đề xuất

```text
Primary 700: #7A263A
Primary 600: #91364C
Primary 100: #F7E8EC
Paper:       #FBF7F0
Surface:     #FFFFFF
Text:        #272321
Muted:       #6F6762
Border:      #E7DED5
Success:     #287A4B
Warning:     #A76513
Danger:      #B42318
Rating:      #D99A17
```

Codex có thể tinh chỉnh contrast nhưng phải giữ tinh thần đỏ rượu + kem.

## Typography

- Font sans dễ đọc, hỗ trợ tiếng Việt.
- Heading rõ, không quá trang trí.
- Body tối thiểu 16px trên nội dung chính.
- Line-height thoáng.

## Spacing

Dùng scale 4px:
`4, 8, 12, 16, 24, 32, 48, 64`.

## Radius

- small: 8px
- medium: 12px
- large: 20px
- pill: 999px

Một floating action button, mở panel. Không hiển thị nhiều nút nổi riêng lẻ.
