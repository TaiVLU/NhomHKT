# M6.0C - Business Foundation Certification Workbook

Version: 2.0
Owner: Technical Lead
Status: Executed

## Purpose

M6.0C certifies the Business Foundation before moving to M6.2. This milestone does not add features; it verifies that the current foundation is stable.

## Goals

- Prove the core business rules are correct.
- Prove the database reflects the approved domain model.
- Prove historical data is not mutated by current catalog changes.
- Prove the system is ready for the next specification phase.

## Scope

In scope:

- Repository health
- Business rules
- Domain invariants
- Database integrity
- Historical integrity
- API contract
- Operational readiness
- Quality gates
- Findings and technical debt

Out of scope:

- New features
- Architecture redesign
- UI/UX redesign
- CQRS redesign
- CatalogReadModel redesign
- Snapshot redesign

## Approved Architecture Baseline

The following decisions are approved and were not reopened during certification:

- CatalogReadModel is the current-state projection.
- Order Snapshot is the historical source of truth.
- Product.primaryCategoryId is the primary-category authority.
- AppError is the error transport baseline.

## Exit Criteria

M6.0C can close only when:

- BLOCKER count is zero.
- Business rules pass.
- Database integrity passes.
- Snapshot integrity passes.
- API contract passes.
- Quality gates pass.
- Technical debt is documented.
- Technical Lead approves closure.
