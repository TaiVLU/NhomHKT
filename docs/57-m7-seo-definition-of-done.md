# M7 SEO Definition of Done

Status: M7.2B IMPLEMENTATION CLOSURE UPDATED

## Purpose

This document defines what M7.2B and later SEO implementation work must satisfy before Technical Lead review. M7.2A is audit-only and does not claim implementation completion.

## Global SEO Done Criteria

| Area | Done Criteria |
|---|---|
| Source boundary | Commerce Core, checkout, cart, inventory, orders, database schema, and API contracts remain unchanged unless a later approved scope says otherwise. |
| Environment | Local demo remains valid; no unsupported public domain is configured or certified. |
| SEO Platform | Metadata and structured data use `apps/web/lib/seo` helpers instead of manual route-specific JSON/string assembly. |
| Tests | Metadata, canonical, robots, sitemap, structured-data, and cross-asset consistency tests cover every changed behavior. |
| Quality gates | Format, lint, type-check, and build pass after implementation. |
| Documentation | Audit findings, implementation evidence, and remaining SEO debt are documented. |

## Route Metadata Done Criteria

Every implemented route should have an intentional SEO class:

- Indexable public route.
- Noindex public utility route.
- Noindex private/auth/transactional route.
- Admin/internal noindex, nofollow, noarchive route.
- 404 or missing-resource noindex route.

For each route, verify:

- title;
- description;
- canonical;
- robots;
- Open Graph title/description/url/image;
- Twitter card/title/description/image;
- route-specific dynamic data where applicable.

## Site Identity Done Criteria

M7.2B should explicitly decide or implement:

- `metadataBase`;
- `applicationName`;
- site name;
- default title and title template;
- manifest ownership;
- icons/favicon/apple touch icon;
- theme color;
- viewport ownership;
- language and locale.

Missing identity assets may remain accepted debt only if documented with priority and rationale.

## Structured Data Done Criteria

Structured data should:

- be generated by `StructuredDataRenderer`;
- use the SEO Platform graph builder;
- align with canonical, Open Graph, and Twitter assets;
- avoid fabricated `AggregateRating`, reviews, FAQ, or policy facts;
- include only schema nodes supported by actual page content;
- pass serialization and validation tests.

## Sitemap And Robots Done Criteria

Sitemap should include:

- implemented indexable public canonical routes;
- category detail routes;
- book detail routes;
- policy/contact routes only when implemented.

Sitemap should exclude:

- admin;
- account;
- cart;
- checkout;
- login/register/reset;
- API;
- 404/error;
- query/filter/search states unless explicitly approved.

Robots should:

- not replace page-level noindex;
- disallow private/admin/transactional/auth paths;
- expose sitemap only when indexing is enabled.

## Social Preview Done Criteria

Open Graph and Twitter assets must be complete enough for local validation:

- title and description are meaningful;
- URL equals canonical;
- image is absolute after SEO asset generation;
- image fallback is stable;
- unsupported public previews are documented as not externally verifiable while local-only.

## AI Search Readiness Done Criteria

AI search readiness is acceptable when:

- page entities are clear from title, heading, breadcrumb, metadata, and JSON-LD;
- product pages expose product/book/offer facts without hallucinated ratings;
- category/catalog pages clearly express collection intent;
- internal links expose product-category relationships;
- deferred content routes are documented instead of silently implied.
