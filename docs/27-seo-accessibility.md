# SEO and Accessibility

## SEO

- Dynamic metadata.
- Canonical.
- Open Graph.
- Sitemap.
- Robots.
- Breadcrumb.
- JSON-LD Product, Offer, AggregateRating, Article, Organization.
- Slug không dấu.
- Product pages indexable.
- Admin, cart, checkout, account: noindex.
- Alt text.
- 404 đúng.

## Accessibility

- Semantic HTML.
- Keyboard navigation.
- Visible focus.
- Label cho form.
- ARIA cho widget, dialog, menu.
- Contrast đạt chuẩn.
- Không chỉ dùng màu để truyền trạng thái.
- Error message gắn với input.
- Escape đóng modal.
